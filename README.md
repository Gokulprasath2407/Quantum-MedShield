# Quantum MedShield

A BB84 Quantum Key Distribution-based secure healthcare communication system with adaptive eavesdropping detection, real-time dashboard, and Qiskit simulation.

## Features

- BB84 Quantum Key Distribution
- Adaptive eavesdropping detection
- Real-time security dashboard
- QBER monitoring
- Secure healthcare communication
- Qiskit-based simulation

## Technologies Used

- Python
- Flask
- Qiskit
- HTML
- CSS
- JavaScript
